# Natural/semi-natural grassland extent x trend

Read `_shared.md` first; those rules always apply.

The prompt asks how grassland changed over the row's window. The verifiable
core is the direction (rising, falling, flat); volunteered peak years or
endpoint figures must match the series.

Subtype notes:

- `direction`: ask whether natural/semi-natural grassland extent rose or fell
  (or how it has developed) over the window.
- `peak_year`: ask which year saw the most grassland lost (or gained) within
  the window — this is the flow, not the extent; check the judge_note for
  which column.
- `change_over_period`: ask how the grassland extent at the end of the window
  compares with the start.

Judge expectations: direction correct for the stated window; volunteered
figures must match the series; figure-free but directionally correct answers
pass with unquantified=true; zero/missing years excluded.
