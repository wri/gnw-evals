How to read this chart

Each row represents one eval test query.
If 50 tests were run, the heatmap will be 50 units tall.

Each column represents an eval score.
For each score, the correct "expected" value is compared to GNW's "actual" response. If no expected value is available, the score is not computed.

Each cell represents a result.
Blue indicates a passing score, rose/pink indicates failing.

This heatmap is interactive.
Click on a cell to see the expected and actual values. Double-click to clear.
